# Requirements

Owner-side evidence bundling requirements. These rows define the E0/F2 change. Adoption remains Pending work until the same approved pull request includes requirements, decisions, source and tests. The existing [qualification contract](qualification-contract.txt) remains the home of the wider tool contract. This focused addition does not claim to migrate or settle other open findings.

| ID | Requirement | Code | Evidence and limits |
| --- | --- | --- | --- |
| LM-37-INSPECT | During a staging sweep, an entry-specific OSError from open, stat or fstat is reported as skipped. Entries already removed remain in the result and later independent entries are considered. Keep the removed/skipped tuple, recovered_staging/skipped_staging JSON keys and existing exit behavior. Root-listing failure, non-OSError, partial recursive removal and final path replacement remain separate limits. | packager.py: recover_sweep | Regression must fail on the original and pass on the proposed source. [Decision LM-D37](decisions.md#lm-d37) describes scope. Evidence is version-specific; no blanket gate pass is inferred. |
| LM-38-NAMESPACE | For cooperating participants, a staging directory this version creates is locked from the moment it has a staging name through publish rename. Create an outside-namespace reservation, lock it, verify identity and rename without overwrite into staging. Never delete reservations during sweep; report them as skipped. | packager.py: _locked_staging, _rename_noreplace_at, pack, recover_sweep | Independent real lock/sweep witnesses must distinguish live pre-lock reservation and locked staging. Earlier producers keep their gap. No hostile namespace or advisory-lock bypass guarantee. [Decision LM-D38](decisions.md#lm-d38) carries the full policy. |
| LM-18-OWN-STAGING | Validate input before allocating staging. After staging ownership transfers to a pack, a normal failure before publication attempts removal only of that attempt's unpublished staging while its lock remains held and named/held identity matches. Preserve the original failure, report cleanup refusal/failure, and never alter permissions or delete reservations, unrelated entries, inputs or published output. Exception subclasses only trigger the new deletion attempt; KeyboardInterrupt and SystemExit are excluded, and no signal handler is added. No cleanup guarantee after an interrupt, termination, SIGKILL, power loss, identity change or an unremovable filesystem obstacle. Locks are advisory, and the identity check followed by path-based removal is not protection against hostile namespace replacement; existing cooperating-participant limits remain. Existing explicit recovery behavior is unchanged. Evidence must distinguish real native failures/crashes from synthetic injected cleanup faults and retain verifier rejection of complete unpublished staging. | packager.py: collect_evidence, pack, _remove_own_staging | Focused staging regressions; C1-b real write error; C1-f and complete-staging/stored-VALID-verdict real after-manifest SIGKILL. Evidence is revision-specific. |
